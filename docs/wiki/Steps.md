# Steps

Generated by steps_page.py from the code; do not edit by hand.

Every goal runs these steps in order: freeze, plan, build, quick checks, tests, merge, after the merge, release.

## Older labels

- build: build
- checks: quick checks
- idea: freeze
- plan: plan
- pr: merge
- qa: tests
- release: release
- review: tests
- ship: tests

## What each step records

- start, end, active minutes, tokens (per attempt, else 'not reported') and the result, as log lines of the goal's record
- a cause for a step that went wrong: a key `<step>:<CODE>`, previewed once with its fix and grouped with repeats (filing ships off in v1.1.0)
