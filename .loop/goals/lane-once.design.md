# Design: lane-once

## Problem Statement

Each step's lane gate reads its own `<slug>.<step>-lane.ok` (`need_lane` in role.py), and `lane()` in lane.py writes that file per step name. The qa, ship and pr steps run the same command (`lane_argv`: `run land --reuse --tier goal`) at the same head, yet each starts its own 15-minute lane. Reviewed DEL-17 promises one lane per head (issue #5734).

## Constraints

- Done lines frozen: one lane per head, its pass satisfies the qa, ship and pr gates; any HEAD move needs a new lane; row selection and budgets unchanged; a head mismatch or a failed lane still refuses, with a negative control; no new file under skills/.
- role.py is at 19,997 bytes (warn 19,000, fail 20,480): the change must be nearly neutral in size there.

## Premises

1. The three lanes run an identical command, so a pass at a head by any one of them proves the other two.
2. The check belongs where a lane starts (`lane()`) and where the gate reads (`need_lane`), not in the callers.
3. A reused pass must also leave the step's own `.last`/`.txt`, so the PR body's "Regression lane" section (`lane_part`) still shows the rows.

## Approaches Considered

- A. Share the pass (chosen). `lane()` returns a pass at once when any lane name holds a pass `.last` at this head and the tree is clean, copying its `.last`, `.txt` and writing this step's `.ok`; `need_lane` accepts an `.ok` equal to HEAD from any of the three names.
- B. One shared file `<slug>.lane.ok`. Rejected: it changes every reader and the lane_part path, and old runs lose their record.
- C. Make ship and pr skip the gate. Rejected: loosens the gate (done line 3).

## Recommended Approach

A, with the helper in lane.py (role.py has no room). Controls: a pass at head H by qa lets ship and pr pass with no second run; a HEAD move needs a new lane; a failed lane and a pass at another head are refused.

## Open Questions

None for the owner.

## Success Criteria

- With a qa pass at HEAD, `role.py lane SLUG ship` and `pr` return pass without starting a lane; the ship and pr gates in goal.py accept it.
- HEAD moved, or the qa lane failed: refused as today.
- Existing lane toys stay green; sizes under the cap; docs, package and private-name checks green.
