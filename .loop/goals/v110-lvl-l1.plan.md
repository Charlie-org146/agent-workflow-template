The rerun runs the same command with its own `TOY_SKIP_FILE` and a fresh temporary HOME (removed after), and KEEPS its exit code. When the rerun exits 0 the row keeps the state `FAIL` and `execute` sets `item["flaky"] = <HEAD commit>` (the field the record already has: its value is the commit on which the row flipped) and prints `FLAKY <id>: failed then passed (rerun once in a fresh HOME).
